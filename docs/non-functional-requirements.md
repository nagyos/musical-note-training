# 非機能要件

## 1. 性能

| ID | 要件 | 目標 |
|----|------|------|
| NFR-PERF-01 | アプリ起動時間 | 冷起動 3 秒以内（中位端末想定） |
| NFR-PERF-02 | 画面遷移 | 100ms 程度で体感遅延なし |
| NFR-PERF-03 | 楽譜描画 | 60fps を維持（単純な五線譜 + 音符） |
| NFR-PERF-04 | オフライン動作 | コア学習機能はネットワーク不要 |
| NFR-PERF-05 | ストレージ | アプリ本体 + データ 100MB 未満（初期） |

**前提**: 高負荷な処理（リアルタイム音声解析・動画レンダリング等）は行わない。

## 3. ユーザビリティ

| ID | 要件 | 詳細 |
|----|------|------|
| NFR-UX-01 | 初回利用 | オンボーディング 3 ステップ以内 |
| NFR-UX-02 | 学習 1 セッション | 5〜15 問で完結できる短い単位 |
| NFR-UX-03 | アクセシビリティ | 文字サイズ・コントラストに配慮（段階的） |
| NFR-UX-04 | 誤操作防止 | デッキ削除等は確認ダイアログ |

### 3.1 デザイン方針 — 縦画面（ポートレート）前提

本アプリの UI・楽譜表示は **スマートフォン縦向きを唯一の主操作向き** とする（`decisions.md` 2026-07-12）。横画面（ランドスケープ）向けのレイアウトは MVP では作らない。

| 項目 | 方針 |
|------|------|
| **画面向き** | 縦固定を原則。端末の回転で UI が横長レイアウトに切り替わる設計はしない |
| **楽譜** | 五線譜は縦長キャンバスの幅に収める。1 問 1 譜面のクイズは中央配置。将来のリズム練習で譜面が時間軸に沿って横に伸びる場合も、**ビューポートは縦画面のまま**（横スクロール or プレイヘッド移動は画面内で完結） |
| **テキスト入力** | デッキ名・カード名、オンボーディング、設定などは縦長 1 カラム。キーボード表示時も縦向きで快適に入力できる余白・スクロールを確保 |
| **ナビゲーション** | ホーム → カタログ → 学習は縦スクロール＋下段アクションを基本。親指操作しやすい配置 |
| **例外** | タブレット・大画面最適化は Phase 4（`T-403`）まで対象外。実装時に `SystemChrome.setPreferredOrientations` 等で縦固定をコード側でも明示する |

**やらないこと**

- 横画面専用の 2 カラム UI（譜面左・選択肢右など）を MVP で用意する
- ランドスケープを推奨するオンボーディングやチュートリアル

|----|------|------|
| NFR-I18N-01 | 対応言語（MVP） | 日本語・英語 |

| NFR-I18N-04 | レイアウト | 長い語句でも UI が崩れない（Flexible / 省略） |
