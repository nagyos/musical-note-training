# 非機能要件

## 1. 性能

| ID | 要件 | 目標 |
|----|------|------|
| NFR-PERF-01 | アプリ起動時間 | 冷起動 3 秒以内（中位端末想定） |
| NFR-PERF-02 | 画面遷移 | 100ms 程度で体感遅延なし |
| NFR-PERF-03 | 楽譜描画 | 60fps を維持（単純な五線譜 + 音符） |
| NFR-PERF-04 | オフライン動作 | コア学習機能はネットワーク不要 |
| NFR-PERF-05 | ストレージ | アプリ本体 + データ 100MB 未満（初期） |

**前提**: 高負荷な処理（リアルタイム音声解析・動画レンダリング等）は行わない。

---

## 2. 可用性・信頼性

| ID | 要件 | 詳細 |
|----|------|------|
| NFR-AVAIL-01 | クラッシュ率 | 本番リリース後、セッションあたり 1% 未満を目標 |
| NFR-AVAIL-02 | データ永続化 | 学習進捗・デッキ・苦手データはローカルに保存 |
| NFR-AVAIL-03 | データバックアップ | 将来: クラウド同期はスコープ外（MVP） |

---

## 3. ユーザビリティ

| ID | 要件 | 詳細 |
|----|------|------|
| NFR-UX-01 | 初回利用 | オンボーディング 3 ステップ以内 |
| NFR-UX-02 | 学習 1 セッション | 5〜15 問で完結できる短い単位 |
| NFR-UX-03 | アクセシビリティ | 文字サイズ・コントラストに配慮（段階的） |
| NFR-UX-04 | 誤操作防止 | デッキ削除等は確認ダイアログ |

---

## 4. 多言語（i18n）

| ID | 要件 | 詳細 |
|----|------|------|
| NFR-I18N-01 | 対応言語（MVP） | 日本語・英語 |
| NFR-I18N-02 | 文字列管理 | Flutter ARB ファイルで一元管理 |
| NFR-I18N-03 | 音名体系 | ドレミ（イロハ）/ CDE 切替 |
| NFR-I18N-04 | レイアウト | 長い語句でも UI が崩れない（Flexible / 省略） |
| NFR-I18N-05 | 将来言語 | 中国語（簡体）・韓国語など拡張可能な設計 |

---

## 5. プラットフォーム

| ID | 要件 | 詳細 |
|----|------|------|
| NFR-PLAT-01 | 対象 OS | Android / iOS（Flutter 標準） |
| NFR-PLAT-02 | 最小 OS バージョン | Flutter 公式推奨に準拠（実装時に確定） |
| NFR-PLAT-03 | 画面サイズ | スマホ縦向きを主、タブレットは将来対応 |

## 6. セキュリティ・プライバシー

| ID | 要件 | 詳細 |
|----|------|------|
| NFR-SEC-01 | 個人情報 | MVP ではアカウント不要、収集最小限 |
| NFR-SEC-02 | 課金 | ストア（Google Play / App Store）経由のみ |
| NFR-SEC-03 | 広告 SDK | 各ストアのポリシー準拠、プライバシーポリシー整備 |
| NFR-SEC-04 | ローカルデータ | 暗号化は MVP では必須としない |

## 7. 収益化・広告

| ID | 要件 | 詳細 |
|----|------|------|
| NFR-MON-01 | 広告配置 | 学習中の集中を妨げない（セッション間・一覧画面等） |
| NFR-MON-02 | 広告頻度 | 過剰なインタースティシャルは避ける |
| NFR-MON-03 | IAP | ユーザー作成カード機能、100〜500円の単発購入 |
| NFR-MON-04 | 復元 | 買い替え端末での購入復元に対応 |
