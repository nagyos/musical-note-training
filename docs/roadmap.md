# ロードマップ

## フェーズ概要

**MVP = v1.0 の出荷範囲。** ディレクトリは [architecture.md](./architecture.md) のフル構成を前提とし、実装だけ段階的に進める。

```
Phase 0: 準備・設計（構成 scaffold 済み）
    ↓
Phase 1: MVP（コア学習 + 単語帳 + 苦手管理）
    ↓
Phase 2: 体験向上（フラッシュ・リズム・和音）
    ↓
Phase 3: 収益化本格化（ユーザー作成 + IAP）
    ↓
Phase 4: 拡張（スケール・コード・多言語追加）
```

---

## Phase 0: 準備・設計

**目標**: Flutter プロジェクト立ち上げ、基本設計の確定

| 項目 | 内容 |
|------|------|
| 期間目安 | 1〜2 週間 |
| 成果物 | プロジェクト雛形、データモデル草案、UI ワイヤー |

- [x] Flutter プロジェクト作成
- [x] ディレクトリ構成・scaffold（[architecture.md](./architecture.md)）
- [ ] ディレクトリ構成・状態管理方針決定
- [ ] 楽譜描画 PoC（五線譜 + 音符 1 つ）
- [ ] データモデル設計
- [ ] ワイヤーフレーム（主要 5 画面）

---

## Phase 1: MVP

**目標**: ストアに出せる最小版。コア学習と単語帳で価値を提供する。

| 項目 | 内容 |
|------|------|
| 期間目安 | 4〜8 週間 |
| リリース | 内部テスト → クローズド β → 公開 |

### 含める機能

| カテゴリー | 内容 |
|------------|------|
| 音符 | ト音記号中心、基本音域 |
| 休符 | 全〜16分休符 |
| 記号 | 反復・臨時・フェルマータ等（基本セット） |
| 強弱記号 | pp〜ff、クレッシェンド |
| 速度記号 | 主要术语 + メトロノーム記号 |
| 単語帳 | デッキ作成・学習セッション |
| 苦手管理 | 誤答記録・苦手復習 |
| 多言語 | 日本語・英語（UI + 音名切替） |
| 広告 | バナー（配置は最小限） |

### 含めないもの（v1.0）

- アカウント・クラウド自動同期
- 教室 / 先生向け（生徒紐づけ）
- 個人向け課金コンテンツ（カスタムカード IAP）
- フラッシュタイマーモード
- リズム練習
- 和音・スケール・コード

### v1.0 で追加するもの（2026-07-12）

- **データのエクスポート / インポート**（端末引き継ぎ、`tasks.md` T-180〜）

## Phase 2: 体験向上

**目標**: 学習モードを増やし、リテンションを上げる。

| 項目 | 内容 |
|------|------|
| 期間目安 | 3〜5 週間 |

- [ ] フラッシュカード（表裏・タイマー式）
- [ ] リズム練習（テンポ同期・8分音符パターン）
- [ ] 和音の識別（基本三和音）
- [ ] 学習統計の強化（ストリーク・週間グラフ）
- [ ] 音符カテゴリーの拡充（ヘ音記号・広い音域）

## Phase 3: リリース後の収益・拡張

**目標（2026-07-12 更新）**: v1.0 以降、**教室 / スクール向け**（生徒紐づけ・苦手把握）を課金候補として検討。個人向けカスタムカード IAP は v1.0 では見送り。

| 項目 | 内容 |
|------|------|
| 着手 | **v1.0 リリース後** |
| 前提 | 認証・サーバー（教室機能時） |

- [ ] 教室向け — 先生–生徒関係・苦手集計（`T-330`〜）
- [ ] 教室向けサブスク / 課金
- [ ] 利用規約・プライバシー（B2B 向け追記）
- [ ] （保留）個人向け五線譜エディタ・カスタムカード IAP
