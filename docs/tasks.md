### 次に進めること（MVP 残り）

厳密な順序は固定しない。**初心者にも分かりやすい内容から**追加する（`decisions.md` Q&A 2026-07-09 参照）。

| 優先の考え方 | タスク | 例 |
|--------------|--------|-----|
| いま動いている音符を厚くする | T-120 拡充 / T-111 | 五線上の基本音域 → 加線の中央ド周辺（既存）→ 音価の段階（全・二・四分） |
| 視覚的に単純なカテゴリーから | T-121 + T-112 | 全休符・四分休符など身近な形状から |
| テキスト中心で入門しやすいもの | T-123 + T-114, T-124 + T-115 | p / f、Andante / Allegro など |
| 意味の説明が必要なものは後ろ | T-122 + T-113 | 反復・臨時・フェルマータ等 |

並行して検討: **T-105**（進捗表示）、**T-143** 残り（苦手の手動追加 UI）、**AppTheme** 微調整（配色は `AppColors` 済み）。

### タスク状態の同期ルール

実装・マージ完了時は **同じ作業で `tasks.md` の状態列を更新する**（エージェント作業の完了条件に含める）。  
「一部」は残タスクが明確なときのみ使う（例: T-111 の符尾、T-112 の休符形状）。
