### リズム練習モード（T-210〜）— `features/rhythm`

**コンセプト**（`optional-features.md` §2 + `decisions.md` 2026-07-12）: 五線譜上に楽譜ルール準拠で並べた**単音＋休符**を、設定テンポに合わせて再生しながら読む。**再生位置の縦線（プレイヘッド）**が左→右に進み、音名・リズム唱名で口ずさみ訓練する。アプリの差別化機能の一つ。

**着手前提（MVP 後）**: T-012（音声 PoC）、T-111（八分符尾）、既存 spatium 描画（#24）。

| T-211 | **feature scaffold** — `features/rhythm/{domain,data,presentation}`、ホーム入口の仮ルート | P0 | T-210 | 未着手 |
| T-212 | **パターン生成**（domain, TDD）— 音価・休符をランダム生成。楽譜ルール（符干向き・休符位置・音域制限・小節内拍数一致）を検証 | P0 | T-210 | 未着手 |

**推奨実装順（縦スライス）**

```
T-210 → T-212 + T-215（domain を TDD で固める）
  → T-213 → T-214 + T-216（無音でプレイヘッドだけ動くデモ）
  → T-217 + T-218（音が鳴る・音名表示）
```

| いま動いている音符を厚くする | T-120 拡充 / T-111 | 五線上の基本音域 → 加線の中央ド周辺（既存）→ 音価の段階（全・二・四分） |
| 視覚的に単純なカテゴリーから | T-121 + T-112 | 全休符・四分休符など身近な形状から |
