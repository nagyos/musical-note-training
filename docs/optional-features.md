# オプション機能アイデア

MVP 以降に検討する、学習体験を広げる機能のアイデア集。優先度は [roadmap.md](./roadmap.md) Phase 2 以降。

---

## 1. フラッシュカード モード

### 1.1 基本（表裏めくり）

- 表: 楽譜上の音符 / 記号のみ
- 裏: 名称・読み方・補足
- タップ or スワイプでめくる
- 「覚えた / まだ」の自己評価

### 1.2 タイマー式フラッシュ

**コンセプト**: フラッシュ暗記の字面通り、決めた秒数以内に次のカードへ自動切替。

| 項目 | 内容 |
|------|------|
| 設定 | 表示時間（1 / 2 / 3 / 5 秒など） |
| 出題 | 表のみ表示 → 時間切れで自動的に裏 or 次へ |
| 目的 | 瞬間的な識別力を鍛える |
| 難易度 | 時間短縮 / カテゴリー混在 |

```
[楽譜表示] ──(N秒)──> [次のカード] ──(N秒)──> ...
                ↓
         （任意）タップで早送り / 一時停止
```

### 1.3 連続出題モード

- 正解するまで次に進まない / 正解 streak 表示
- 苦手項目を優先的に混ぜる

## 2. リズム練習モード

**コンセプト**: 楽譜上に並んだ音符を、テンポに合わせて読みながら音を鳴らし、リズム感と読譜を同時に鍛える。

### 2.1 テンポ同期再生

| 項目 | 内容 |
|------|------|
| 表示 | 五線譜上に音符列 + 再生位置インジケータ |
| 動作 | BPM に合わせてカーソルが進み、音符位置で音が鳴る |
| 同時表示 | 現在の音名（ド / C 等）を画面に表示 |
| 設定 | BPM スライダー、メトロノーム ON/OFF |

```
拍:  1    2    3    4
     ♩    ♪♪   𝄽    ♩
     ↓    ↓         ↓
    [ド] [レ][ミ]  [休] [ファ]
```

### 2.2 リズムパターン生成

- 8分音符を基本単位
- 休符をランダムに挿入（配置・長さ）
- 難易度: 休符密度 / テンポ / 音域

| 難易度 | 内容 |
|--------|------|
| Easy | 4分音符のみ、休符なし |
| Medium | 8分音符 + 4分休符 |
| Hard | 8分音符 + ランダム休符 + テンポ UP |

### 2.3 フィードバック

- ユーザーがタップ / キー入力で音名を答える（オプション）
- テンポずれの許容範囲（将来）

## 4. ユーザー作成カード（課金機能）

Phase 3 で実装予定。ここでは UX の方向性のみ。

### エディタ機能

- 五線譜上をタップして音符配置
- 複数音選択で和音
- 符尾の長さ（4分 / 8分等）
- ト音 / ヘ音切替
- プレビュー（描画 + 再生）

### 単語帳連携

- 作成したカードを「答え」として保存
- 公式デッキと混在可能
- エクスポート（将来）

### 課金 UX

| 状態 | 体験 |
|------|------|
| 未購入 | エディタプレビューのみ / 1 枚まで試作 |
| 購入後 | 無制限作成 + デッキ組み込み |

価格帯: **100〜500円**（最終価格はストア調査後に決定）
