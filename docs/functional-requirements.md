# 機能要件

## 凡例

| 優先度 | 意味 |
|--------|------|
| **MVP** | 初回リリースに含める |
| **将来** | MVP 以降のフェーズ |
| **オプション** | あると良いが優先度は低い |

---

## 1. 学習コンテンツ（カテゴリー別）

### 1.1 音符 【MVP】

| ID | 要件 | 詳細 |
|----|------|------|
| FR-NOTE-01 | ト音記号・ヘ音記号の五線譜上の音符を表示できる | 初音〜高音域を段階的に |
| FR-NOTE-02 | 音符の名称（ドレミ / CDE など）を問う形式を提供 | 表示モード切替 |
| FR-NOTE-03 | カテゴリー内をサブレッスンに分割 | 例: 中央ド周辺 / 1オクターブ上 など |
| FR-NOTE-04 | 正誤フィードバックと簡易解説 | 間違えた場合に正解を表示 |

### 1.2 休符 【MVP】

| ID | 要件 | 詳細 |
|----|------|------|
| FR-REST-01 | 全休符〜64分休符を表示・識別 | 形状と名称 |
| FR-REST-02 | 音符と同様のクイズ形式 | 選択式 or 入力式 |

### 1.3 記号 【MVP】

| ID | 要件 | 詳細 |
|----|------|------|
| FR-SYM-01 | 反復記号・フェルマータ・臨時記号など基本記号 | 段階的に追加 |
| FR-SYM-02 | 記号の意味を問う | 名称 + 用途の説明 |

### 1.4 強弱記号 【MVP】

| ID | 要件 | 詳細 |
|----|------|------|
| FR-DYN-01 | pp / p / mp / mf / f / ff など | 記号と意味 |
| FR-DYN-02 | クレッシェンド・デクレッシェンド | 記号の識別 |

### 1.5 速度記号 【MVP】

| ID | 要件 | 詳細 |
|----|------|------|
| FR-TEMPO-01 | Largo / Andante / Allegro など基本术语 | 名称とおおよその BPM 感 |
| FR-TEMPO-02 | メトロノーム記号（♩=120 等）の読み方 | 数値の意味 |

## データモデル（概要）

```
Category          # 音符 / 休符 / 記号 等
  └ Lesson        # サブレッスン
       └ Card     # 1 問分（楽譜データ + 正答 + 解説）

Deck              # ユーザー作成デッキ
  └ DeckCard      # Card への参照 or カスタム定義

WeakItem          # 苦手項目（Card 参照 + 統計）

UserSettings      # 言語・音名モード・課金状態
CustomCard        # ユーザー作成（課金後）
```

詳細は実装フェーズで `docs/data-model.md` として切り出す予定。
