# アプリ概要

## コンセプト

ピアノの楽譜に登場する記号を、**カテゴリー別に体系的に学び**、**単語帳のように反復**して定着させる学習アプリ。

開発者自身が音楽理論・座学を学びながら作ることを前提とし、コンテンツもアプリも段階的に育てていく。

## 解決したい課題

- 楽譜の音符・休符・各種記号をバラバラに覚えがちで、体系化された学習手段が少ない
- 既存アプリは単音中心が多く、和音や自由な音符セットで練習しにくい
- 苦手な記号だけを集中的に復習する仕組みが欲しい

## ターゲットユーザー

| ユーザー | ニーズ |
|----------|--------|
| ピアノ初心者 | 音符・休符の読み方を覚えたい |
| 楽譜読みの復習者 | 記号・強弱・速度記号を整理して学び直したい |
| 自習型の学習者 | 単語帳のように自分のペースで反復したい |

## 主要機能（概要）

1. **カテゴリー別学習** — 音符 / 休符 / 記号 / 強弱 / 速度記号などを段階的に学ぶ
2. **単語帳** — 覚えられていない項目をデッキに追加し、反復練習
3. **苦手管理** — 正答率・回答時間などから苦手項目を自動または手動で管理
4. **カスタムデッキ** — 開発者提供外の音符・和音・記号セットをユーザーが作成（課金開放）
5. **（将来）フラッシュ・リズム練習** — 複数モードで読譜・リズム感を鍛える

## 収益モデル

| 要素 | 方針 |
|------|------|
| 基本利用 | 無料 |
| 広告 | 適宜表示（学習フローを妨げない配置） |
| 課金（IAP） | ユーザー作成カード機能を **100〜500円** で開放 |
| 高負荷処理 | なし（オフライン中心・軽量な UI / 描画） |

## 技術スタック（想定）

| 項目 | 選定 |
|------|------|
| フレームワーク | Flutter |
| 言語 | Dart |
| 状態管理 | 未定（Riverpod / Bloc など後で決定） |
| DB | Turso (libSQL) + embedded replica（Phase 0から） |
| 楽譜描画 | 未定（CustomPainter / 既存パッケージ調査） |
| 音声 | 未定（flutter_midi / just_audio + サンプル） |
| 課金 | in_app_purchase |
| 広告 | google_mobile_ads |
| 多言語 | flutter_localizations + intl |
